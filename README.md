# سندتيوب — SanadTube

منصة عربية ذكية لمساندة صناع المحتوى على YouTube عبر مجتمع تعاوني حقيقي، أدوات تحليل أداء متقدمة، وتبادل الخبرات المهنية.

## 📄 وثيقة المتطلبات والتصميم الفني
للاطلاع على المتطلبات الوظيفية والمعمارية وهيكل قاعدة البيانات ومسارات الـ API بالكامل، يرجى مراجعة [PRD.md](file:///c:/xampp/htdocs/sanadtube/PRD.md).

## 🛠️ البنية التقنية المعتمدة
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.
- **Backend:** Laravel API.
- **Database:** PostgreSQL.
- **Cache & Queue:** Redis.
- **Integrations:** YouTube Data API v3 & YouTube Analytics API.
